# LESSONS.md — このプロジェクトで得た教訓

## 2026-07-12 初期実装(PWA+GAS)

- 症状: 実装一式のコミットを main へ直接 push した(グローバル CLAUDE.md の「main への直接 push はしない。作業はブランチを切る」に違反)。プロジェクト初期化指示の「初回コミットをプッシュ」に引きずられ、実装コミットもそのまま main で作業した。
- 根本原因: Phase 0 の「やらないこと」にグローバル Git 規約を転記しなかったため、突き合わせ対象から漏れた(証拠: git log で 4e54450 が main 直接コミット)。
- 教訓: Phase 0 で完了条件と一緒に「リポジトリ規約(ブランチ運用・push先)」を必ず1行で確認する。新規リポジトリでも2コミット目以降はブランチを切る。

## 2026-07-12 ヘッドレスChromeのスクリーンショット検証

- 症状: `chrome --headless --window-size=412,915 --screenshot` の画像で右列がはみ出して見え、CSSレイアウト崩れと誤診しかけた。
- 根本原因: このChromeでは `--window-size` がviewportに反映されず innerWidth=504 固定で描画され、画像だけが412幅に切り取られていた(証拠: `--dump-dom` で innerWidth=504 を実測)。
- 教訓: ヘッドレスのスクリーンショットで崩れを見つけたら、修復前にまず innerWidth を実測して撮影アーティファクトか裁定する。幅指定の検証は「指定幅のiframeに実ページを埋め込む」方式が確実。
